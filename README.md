# 招聘数据分析岗位 EDA 项目
> 项目重心：数据分析、数据清洗、可视化，爬虫仅作为数据源获取工具(来自GitHub上面开源的项目boss-zhipin-scraper)

## 项目简介
本项目基于BOSS直聘数据分析岗位招聘数据，完成从原始数据读取、清洗、探索性分析、可视化到业务结论输出的完整数据分析流程。
目标：挖掘（重庆，成都）数据分析岗位的薪资分布、城市需求、技能关键词、学历与经验门槛，为求职学习提供参考。

数据源说明：
原始JSON数据通过开源项目 `boss-zhipin-scraper` 改造采集，**仅用于个人学习研究，禁止商用、大规模抓取**。
仓库内只放入脱敏抽样后的小样数据，不存放完整原始爬虫脚本。数据采集于2026_11_7.

## 技术栈
- Python
- Pandas、NumPy：数据清洗、特征处理、统计分析
- Matplotlib：可视化绘图
- Jupyter Notebook：交互式分析
- MySQL（可选）：清洗后数据入库，SQL查询分析

## 项目目录结构
- data/
  - sample_data.json      # 脱敏抽样后的岗位小样数据
- 重庆成都数据分析师岗位维度分析.ipynb  # 核心分析代码：清洗、EDA、可视化、结论
- README.md                 # 项目说明文档
## 分析内容
1. 数据清洗：
   - 薪资区间拆分，计算薪资均值
   - 缺失值、重复岗位数据处理
   - 统一城市、经验、学历标签
2. 探索分析：
   - 不同城市岗位数量 & 薪资对比
   - 不同工作经验对应的薪资分布
   - 岗位高频技能关键词统计（Python、SQL、BI等）
   - 学历要求分布
3. 可视化：柱状图、箱线图、词云等
4. 业务总结：输出数据分析岗求职建议
